# iPhone Importer

Небольшое приложение для Windows, которое копирует фото и видео с iPhone по USB на компьютер.
Одно окно, одна кнопка. При повторном запуске копируются только новые файлы.

- **Оригиналы байт в байт.** HEIC, ProRAW/DNG, HEVC-видео приходят как есть, без перекодирования в JPG/H.264.
- **Быстро.** Копирование идёт напрямую через AFC, а не через WPD/«Проводник». Скорость упирается в USB:
  ~35 МБ/с на Lightning (USB 2.0).
- **Только новое.** Журнал импорта запоминает, что уже скопировано. Подключили телефон, нажали кнопку, получили свежие снимки.
- **Без потерь.** Если оборвался кабель, телефон заблокировался или вы нажали «Отменить», недокопированный файл
  удаляется, а следующий запуск продолжает с того же места. Существующие файлы никогда не перезаписываются.
- **Один `.exe`.** Без установщика и рантаймов, только системные DLL.

## Требования

- Windows 10/11 x64.
- Приложение [**Apple Devices**](https://apps.microsoft.com/detail/9NP83LWLPZ9K) из Microsoft Store. Оно ставит службу
  usbmuxd, через которую iPhone виден по USB. Если её нет, программа сама предложит открыть страницу в Store.
- iPhone, подключённый **кабелем**: разблокированный, с ответом «Доверять» на запрос этого компьютера.

## Как пользоваться

1. Запустите `iphone-importer.exe` и подключите iPhone.
2. Если на телефоне появился запрос «Доверять этому компьютеру?», нажмите «Доверять».
3. Программа посчитает новые файлы и покажет, сколько фото, видео и какой у них объём.
4. При желании смените папку кнопкой «Изменить…». По умолчанию это `Изображения\iPhone`.
5. Нажмите «Импортировать N файлов». После завершения нажмите «Открыть папку».

Чтобы скопировать всё ещё раз, независимо от журнала, есть кнопка «Скопировать всё заново…» (с подтверждением).

### Куда кладутся файлы

```
<папка>\
├─ .import-log          журнал: что уже импортировано
└─ 2026-10-07\          дата импорта (не дата съёмки)
   ├─ Фото\             HEIC HEIF JPG JPEG PNG DNG GIF TIFF WEBP
   └─ Видео\            MOV MP4 M4V
```

- Прочие файлы из `DCIM` (например, `.AAE` с правками) не импортируются.
- Если имя уже занято, файл получает суффикс: `IMG_0001 (1).HEIC`, `IMG_0001 (2).HEIC`, …
- Файл считается уже импортированным, если в журнале есть запись с тем же путём на телефоне и тем же размером.
  Удалите `.import-log`, и программа будет считать новыми все файлы.
- Выбранная папка хранится в `%APPDATA%\iphone-importer\config.txt`.

### Если что-то пошло не так

| Ситуация | Что происходит |
|---|---|
| «Нет приложения Apple Devices» | Установите его из Microsoft Store (кнопка прямо в окне). |
| «Нужно доверие» | Разблокируйте iPhone и нажмите «Доверять». Если запрос не появляется, откройте Apple Devices: оно обновит сопряжение. |
| Выдернули кабель / телефон заблокировался | Импорт останавливается. Подключите снова и нажмите «Импортировать»: продолжится с места остановки. |
| Не удалось прочитать отдельный файл | Файл пропускается, остальные копируются. В конце показывается список неудачных; при следующем запуске они попробуются снова. |
| Мало места на диске | Импорт не начинается: программа покажет, сколько места нужно и сколько свободно. |

## Сборка из исходников

Проект собирается тулчейном `x86_64-pc-windows-gnu` (закреплён в `rust-toolchain.toml`), поэтому Visual Studio
Build Tools не нужны. Нужны [rustup](https://rustup.rs) и MinGW:

```powershell
winget install BrechtSanders.WinLibs.POSIX.UCRT --scope user
# после установки откройте новый терминал, чтобы обновился PATH
```

Команды `cargo` запускайте из **PowerShell**: в Git Bash `link` указывает на GNU coreutils, и линковка ломается.

```powershell
cargo build --release          # target\release\iphone-importer.exe
cargo test                     # unit-тесты, телефон не нужен
cargo test -- --ignored --nocapture   # тест на реальном iPhone (подключён, разблокирован, доверен)
```

Проверить, что `.exe` зависит только от системных DLL:

```powershell
objdump -p target\release\iphone-importer.exe | Select-String 'DLL Name'
```

## Как устроено

Rust + [egui](https://github.com/emilk/egui) (`eframe`). Доступ к телефону через крейт
[`idevice`](https://crates.io/crates/idevice): usbmuxd → lockdown → AFC, чистая Rust-криптография (`rustcrypto`).

| Модуль | Что делает |
|---|---|
| `device.rs` | Находит iPhone по USB (Wi-Fi-подключение игнорируется), открывает AFC, перечисляет `/DCIM/*/*`, читает файлы блоками по 1 МБ. Синхронная обёртка над async `idevice`. |
| `import.rs` | Цикл копирования. Ничего не знает про iPhone: источник байтов передаётся замыканием, поэтому полностью покрыт тестами с фейковыми источниками. |
| `journal.rs` | Журнал `.import-log`: строка `путь_на_телефоне<TAB>размер`, `fsync` после каждой записи. |
| `worker.rs` | Фоновый поток: опрашивает устройство каждые 2 с, считает новые файлы, запускает импорт, шлёт события в GUI. |
| `main.rs` | Окно egui. |

Как обеспечивается целостность:

1. Файл копируется в `имя.part`.
2. `fsync`, затем переименование в свободное имя (существующие файлы не трогаются).
3. Только после этого в журнал дописывается строка.

Поэтому запись в журнале всегда означает, что файл лежит на диске. Обратное допустимо: файл без записи просто
скопируется ещё раз. Оставшиеся `.part` удаляются перед следующим импортом.

Копирование сознательно последовательное: узкое место — USB, параллельность ничего не даёт.

Подробности и обоснование решений: [`docs/superpowers/specs/2026-10-07-iphone-importer-design.md`](docs/superpowers/specs/2026-10-07-iphone-importer-design.md).

## Чего здесь нет (и не планируется)

Удаление с телефона, конвертация HEIC/HEVC, превью и выбор отдельных файлов, импорт по Wi-Fi,
режим без Apple Devices (WPD), macOS/Linux.
