# iPhone Importer — дизайн

Дата: 2026-10-07

## Цель

Настольное приложение для Windows, которое быстро копирует фото и видео с iPhone по USB
в локальную папку. Одно окно, одна главная кнопка, повторный импорт берёт только новое.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Язык / GUI | Rust + egui (`eframe`), один `.exe` | Нативное окно без рантайма |
| Доступ к телефону | AFC через usbmuxd из Apple Devices (крейт `idevice`) | Оригиналы байт-в-байт, максимум скорости USB. WPD отвергнут из-за скорости и перекодирования HEIC→JPG |
| Зависимость у пользователя | Apple Devices из Microsoft Store | Без неё usbmuxd нет; свой WinUSB-драйвер и поставка компонентов Apple отвергнуты |
| Сборка | `x86_64-pc-windows-gnu` + MinGW (WinLibs), `idevice` с `rustcrypto` | Без Visual Studio Build Tools; без C-криптографии |
| Формат | Оригиналы, без конвертации | |
| Что импортировать | Только новые (по журналу) + «Всё заново» | |

## Результаты пробного запуска (spike)

- usbmuxd на `127.0.0.1:27015`, iPhone виден дважды — USB и Wi-Fi; брать USB.
- Обход `/DCIM`: 5625 файлов, 49,7 ГБ за 2,5 с.
- Копирование 1069 МБ MOV: 35,5 МБ/с (потолок USB 2.0, Lightning).
- AFC-файл надо закрывать явно (`close().await`).
- Устаревшая запись сопряжения даёт `InvalidHostID` — лечится «Доверять» через Apple Devices.

## Раскладка файлов

```
<цель>\
└─ ГГГГ-ММ-ДД\        дата старта импорта
   ├─ Фото\           HEIC HEIF JPG JPEG PNG DNG GIF TIFF WEBP
   └─ Видео\          MOV MP4 M4V
```

- Остальные расширения (AAE и пр.) не импортируются.
- Регистр расширения не важен.
- Имя занято → `IMG_0001 (1).HEIC`, `(2)` … Существующие файлы не перезаписываются.
- Цель по умолчанию: `Изображения\iPhone`; выбранная папка хранится в
  `%APPDATA%\iphone-importer\config.txt` (одна строка).

## Архитектура

Один крейт, четыре модуля.

| Модуль | Задача | Зависимости |
|---|---|---|
| `device.rs` | usbmuxd → USB-подключение → AFC; обход `/DCIM/*/*` (путь, размер); чтение файла блоками; закрытие | `idevice`, `tokio` |
| `import.rs` | Классификация фото/видео, фильтр по журналу, копирование через `.part` + rename, имена `(n)`, очистка `.part`, прогресс, отмена | stdlib |
| `journal.rs` | `<цель>\.import-log`: строка `путь_на_телефоне\tразмер`, дописывается после успешного файла | stdlib |
| `main.rs` | Окно egui, фоновый поток с tokio runtime, канал событий в GUI, `AtomicBool` для отмены | `eframe`, `rfd` |

Поток: «Импорт» → фоновый поток: подключение → обход → фильтр по журналу →
последовательное копирование (параллельность не даёт выигрыша — упор в USB) →
после каждого файла строка в журнал и событие `Progress` в GUI.

`import.rs` не знает про AFC: источник передаётся замыканиями (список файлов, открыть
поток чтения), что позволяет тестировать без телефона.

## Экран

```
┌─ iPhone Importer ─────────────────────────────────┐
│  ● iPhone подключён (00008110-…)                  │
│  Папка: D:\iPhone                     [Изменить]  │
│  Новых: 340 файлов — 280 фото, 60 видео, 4,2 ГБ   │
│  [  Импортировать  ]   [ Всё заново… ]            │
│  ████████████░░░░░░░░  58%   212 / 340            │
│  35,1 МБ/с · осталось ~0:51 · IMG_4027.HEIC       │
│                                    [ Отмена ]     │
└───────────────────────────────────────────────────┘
```

| Состояние | Экран |
|---|---|
| usbmuxd не отвечает | «Не найдено Apple Devices» + «Открыть в Microsoft Store» (`ms-windows-store://pdp/?productid=9NP83LWLPZ9K`) |
| Нет устройства | «Подключите iPhone кабелем»; опрос каждые 2 с, при появлении — автоподсчёт |
| Не сопряжён / заблокирован | «Разблокируйте iPhone и нажмите „Доверять“» |
| Подсчёт | Спиннер «Считаю новые файлы…» |
| Готов | «Новых: …» или «Всё уже импортировано» |
| Импорт | Прогресс, скорость, ETA, текущий файл, «Отмена» |
| Завершено | «Импортировано N файлов в …» + «Открыть папку»; список неудачных, если есть |

«Всё заново…» требует подтверждения с числом файлов и объёмом.

## Ошибки и целостность

| Ситуация | Поведение |
|---|---|
| Обрыв кабеля / блокировка | Удалить текущий `.part`, стоп, сообщение «импортировано X из Y, подключите и нажмите „Импортировать“». Продолжение — естественно через журнал |
| Ошибка чтения одного файла | Пропустить (не в журнал), продолжить; в конце список неудачных |
| Размер прочитанного ≠ размер на телефоне | Ошибка этого файла |
| Нет места / нет прав | Стоп сразу. Перед стартом: свободное место < объём новых → предупреждение |
| Отмена | Как обрыв |
| Хвосты `.part` | Удаляются в папке дня перед импортом |

Инвариант: строка в журнале появляется только после успешного rename `.part` → итог.
Файл без записи в журнале возможен (скопируется ещё раз), запись без файла — нет.

## Тестирование

- `#[test]` в `import.rs` / `journal.rs`: классификация, фильтр по журналу, суффикс `(n)`,
  очистка `.part`, журнал (запись/чтение), обрыв посреди файла (замыкание-источник
  возвращает ошибку) → нет `.part`, нет записи в журнале.
- Ручная проверка на iPhone: импорт; повтор → «0 новых»; выдернуть кабель посреди и
  продолжить; «Всё заново».

## Вне объёма

Удаление с телефона, конвертация HEIC/HEVC, превью, выбор отдельных файлов, Wi-Fi,
WPD-режим без Apple Devices, macOS/Linux.
